I take projects from an empty repository to a running service: HTTP API, database schema
and migrations, Telegram bots and Mini Apps, then deployment to a VPS behind nginx with TLS.

## Projects

### [DockerFile-Parser](https://github.com/Chatterxton/DockerFile-Parser)

`Go` `SVG` `Docker`

Parses `docker-compose.yaml` and Helm charts and draws a service dependency graph: which
service talks to which one over the network. Links are resolved from four sources at once,
including a heuristic over `environment` variables, so `DATABASE_URL=postgres://db:5432/app`
becomes a real edge to the `db` service. External hosts and databases are detected
automatically, networks turn into group frames, and a focus mode narrows the graph down to
one service and its neighbours. Exports to SVG, PNG, Mermaid and Graphviz.

Ships as one static binary. The page, styles and fonts are embedded with `go:embed`, so it
pulls nothing from a CDN and works without internet access.
